## Описание проекта

В данной практической работе разработано многостраничное веб-приложение на Flask, состоящее из трёх страниц:
1. **Главная (`/`)** — вводная информация об учебном проекте;
2. **О проекте (`/about`)** — сведения о стеке технологий и целях разработки;
3. **Лог изменений (`/changelog`)** — история версий приложения от 0.1 до 0.5.

Общая структура сайта (шапка, меню навигации, подвал, базовые стили) вынесена в базовый HTML-шаблон `templates/base.html`, а дочерние страницы наследуют его с помощью тегов шаблонизатора Jinja2 `{% extends "base.html" %}` и `{% block content %}`. Ссылки меню формируются динамически функцией `url_for(...)`.

## Инструкция по запуску

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск приложения
Перейдите в каталог с исходным кодом:
```bash
cd src
python app.py
```

Сервер откроется на локальном порту: [http://127.0.0.1:5000](http://127.0.0.1:5000).

### 3. Запуск тестов
Для проверки работоспособности всех маршрутов и структуры выполните:
```bash
python tests/test_all.py
```
